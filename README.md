# TERN
TERN - ist ein schnörkelloses, wunderschön ruhiges Quiz über Geschichte 🏛️, Geografie 🗺️ &amp; Kulturen 🎎.
Jede richtige Antwort zeigt dir exakt auf einem 3D-Globus 🌍 (three-globe), woher die Frage stammt — mit Ländergrenzen 🗺️, dezenten Pins 📍 und einem Fun-Fact Nugget 🧠✨.
